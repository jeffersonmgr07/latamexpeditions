# LATAM Expeditions — inventario de imágenes de todas las fichas

**Revisión de 09/11/2026:** rutas de productos en `paquetes/` y `experiencias/`, cruzadas con el catálogo y con los HTML vigentes. Se verificó la existencia exacta de cada nombre en `assets/img/`.

## Dónde subir fotografías

1. En GitHub abre la carpeta [`assets/img/`](assets/img/).
2. Selecciona **Add file → Upload files** y sube una fotografía horizontal, idealmente de **1200 × 800 píxeles (3:2)**.
3. Respeta **exactamente el nombre, los guiones, el acento si existe y la extensión** de la columna «Archivo usado por la ficha». Si el archivo ya existe, en GitHub deberás reemplazarlo conservando el mismo nombre.
4. Para cambiar a un nombre diferente, actualiza `assets/data/catalog.json` y regenera las fichas; no basta con subir un nombre nuevo al azar.

**Importante:** «Archivo usado por la ficha» es la imagen que el HTML carga para el encabezado y/o imagen principal; en fichas antiguas puede derivarse de la imagen de vista previa. La columna SEO solo aparece si tiene una ruta diferente. Hay excepciones explícitas: **Medellín Esencial** usa en la ficha una panorámica de Comuna 13, aunque mantiene otra imagen `og:image`; cinco tours Cibeles también usan rutas particulares distintas a la del catálogo.

**Resumen:** 132 páginas · 122 imágenes encontradas · 6 archivos principales faltantes · 4 redirecciones sin fotografía propia.
