# Lista de imágenes requeridas para Latam Expeditions

Todas las imágenes deben subirse en una sola carpeta:

`assets/img/`

No se crean subcarpetas por país ni por sección. El seguimiento se hace con nombres descriptivos y numeración.

## Recomendación técnica

- Formato recomendado: `.jpg` o `.webp`.
- Peso ideal por imagen: 250 KB a 500 KB para cards y 700 KB a 1.2 MB para hero.
- Proporción hero: 16:9 o 21:9.
- Proporción cards: 4:3.
- Evitar textos dentro de las fotos para facilitar multi-idioma.
